Preparing web installer

MAYDAY OBI · ESP32-S3

Checking for available firmware.

  1. Open this page in Chrome or Edge on a computer.
  2. Connect the board with a USB data cable.
  3. Click Install and select the board's USB port.
  4. Keep the cable connected until installation is complete.

For the 3.5-inch board shown below. Disconnect the Makita battery before installation. Depending on the install option, existing settings may be erased.

USB port not listed or connection failed?

Use a data cable, not a charge-only cable, and close other serial monitor programs. If the board still does not appear, hold BOOT, briefly press RESET, release BOOT, then reconnect. Button names and steps can vary by board.

Board & wiring

ESP32-S3 with a 3.5-inch touchscreen. See the board photos, Makita communication wiring, and battery power wiring.

Lithium-ion battery wiring

View diagram ↗ View diagram ↗

Connect battery + / − to the P5 power terminals. Add a 100 kΩ resistor to each voltage-sense wire, then connect the joined point to IO9 marked on the board.

Use a protected 1-cell (1S) battery and check the actual polarity marked at P5.

Based on public information from the original OBI project. These boards have not been verified with MAYDAY OBI.

  • LIP5002 · LIPW001MC908JK3E
  • LIPW002 · 003 · 005 · 006uPD78F0513
  • LIPW011 · 012 · 013uPD78F0513
