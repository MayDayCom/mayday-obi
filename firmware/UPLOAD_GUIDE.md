# 펌웨어 두 파일 배포

같은 빌드에서 생성된 다음 두 파일을 이 폴더에 **같은 커밋으로** 올립니다.

- `firmware.bin`: 앱 단독 파일. 기기에 있는 펌웨어 업데이트 기능에서 사용합니다.
- `firmware.factory.bin`: 부트로더·파티션 테이블·앱을 포함하는 최초 설치 및 복구용 파일. 웹 USB 설치에 사용합니다.

PlatformIO 빌드 결과는 `.pio/build/jc3248w535/`에 생성됩니다. 소스의 `APP_VERSION` 한 곳에서 버전을 지정하고 빌드하면, 두 BIN 내부에 같은 버전·빌드 시각이 포함됩니다. 페이지 HTML이나 `manifest.json`의 버전을 매번 수정할 필요가 없습니다.

웹페이지는 BIN 내부의 `MAYDAY_OBI_META_V1|board=jc3248w535|version=...|build=...|END` 레코드를 읽습니다. 두 파일의 버전·빌드와 앱 바이트가 일치해야 설치할 수 있습니다. 업로드 도중 한 파일만 교체됐거나 다른 빌드 파일이 섞인 경우에는 설치를 일시 중단합니다.

표시 버전, 연결된 기기와의 비교 기준, ESP Web Tools 설치 안내가 모두 같은 BIN에서 읽은 버전을 사용합니다. USB 설치에는 검사한 파일 자체를 사용합니다.

## 기존 배포본 호환

현재 기존 `firmware.bin`은 v1.10c 통합 이미지입니다. 새 `firmware.factory.bin`이 아직 없을 때만 이 구형 파일을 통합 이미지로 확인한 후 기존 manifest의 v1.10c 정보를 사용합니다. 새 형식의 두 파일을 함께 올리면 자동 버전 읽기로 전환됩니다.

새 이름의 통합 이미지가 있는데 버전 정보가 없거나 두 파일이 맞지 않으면 구형 배포본으로 우회하지 않습니다. 새 소스로 다시 빌드한 두 파일을 사용하세요.

## 설치 방식

두 파일 배포와 버전 자동 표시는 USB의 파티션 선택 업데이트를 구현한 것이 아닙니다. 일반 BIN은 기기의 기존 업데이트 기능에서 사용하고, 현재 웹 USB 설치는 통합 이미지로 최초 설치·복구합니다.
