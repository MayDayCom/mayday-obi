# 웹 업데이트와 자동 재부팅

일반 firmware.bin은 실행 중인 앱이 아닌 반대편 OTA 파티션에 기록합니다. 기록·SHA-256·ESP 이미지·보드/버전 검증에 성공한 경우에만 새 파티션으로 부팅을 전환합니다. 현재 앱은 반대편에 남으며 기기의 기존 복구 기능으로 선택할 수 있습니다.

## USB 웹 업데이트

1. INFO/READY 응답에서 현재/대상 파티션과 허용 전송 크기를 확인합니다.
2. CHUNK가 없는 기기에는 128바이트씩 전송하며 매 블록의 ACK를 기다립니다. CHUNK를 알리면 최대 4096바이트까지 기기가 지원하는 크기를 사용합니다.
3. AUTO_BOOT=1 기기에는 MAYDAY_OTA_END_AUTO를 보내 검증과 부팅 전환을 함께 요청합니다.
4. 기존 USB 수신기에는 MAYDAY_OTA_END로 검증 완료를 확인한 후 MAYDAY_OTA_BOOT를 같은 연결에서 자동 전송합니다.
5. REBOOTING 응답을 받은 뒤 웹 화면에 “업데이트가 완료되었습니다. 기기가 자동으로 재부팅됩니다.”를 표시하고 팝업을 닫습니다.
6. 파일 검증이나 전송이 실패하면 재부팅 명령을 보내지 않습니다.

v1.10v는 RX 큐가 8KB 이상이면 CHUNK=4096, 4KB 이상이면 CHUNK=1024, 그보다 작으면 CHUNK=128을 알립니다. USB 수신 중에는 전송을 우선 처리하고 화면은 100ms 간격으로 갱신합니다. 웹은 헤더와 데이터를 함께 보내고 수신 ACK에 따라 진행률을 최대 100ms 간격으로 표시합니다. 전송 중 버튼은 실제 비활성화와 흐린 표시를 함께 적용하고 중복 실행을 차단합니다. 준비·수신량·검증 단계는 각각 구분해 표시합니다.

일반 END, DEFER 명령과 기기 선택 화면은 기존 도구와의 호환을 위해 남겨 두지만 현재 웹 업데이트는 완료 후 별도 재부팅 선택을 요구하지 않습니다.

## 기기 Wi-Fi 업데이트 페이지

성공적으로 검증된 업로드만 완료로 처리합니다. 브라우저에 자동 재부팅 안내를 보내고 현재 버전을 복구용으로 기록한 뒤 새 이미지로 자동 재부팅합니다. 빈 요청, 쓰기 오류, 검증 실패, 업로드 중단은 자동 재부팅하지 않습니다.

이는 기존 수동 복구 기능을 유지한 구현입니다. 부팅한 새 앱의 상태를 자동 진단하고 되돌리는 부트로더 자동 롤백을 새로 설정한 것은 아닙니다.

## 명령

- MAYDAY_INFO? / MAYDAY_VERSION?: 기기 정보 및 버전
- MAYDAY_OTA_BEGIN|SIZE=...|SHA256=...|APP=...|FW=...
- MAYDAY_OTA_DATA|OFFSET=...|SIZE=... 다음에 해당 길이의 바이너리
- MAYDAY_OTA_END_AUTO: 검증 완료 후 새 파티션으로 자동 부팅
- MAYDAY_OTA_END: 검증 후 대기 보관하는 이전 도구 호환 명령
- MAYDAY_OTA_BOOT: 검증된 대기 이미지로 부팅 전환
- MAYDAY_OTA_DEFER / MAYDAY_OTA_ABORT: 이전 도구 호환 및 수신 취소

전송 중 20초 동안 새 데이터가 없으면 수신을 중단하며 부팅 대상은 바꾸지 않습니다. 대상 파티션의 이전 대기 이미지는 새 전송을 시작하면 지워질 수 있습니다.
