마끼다 LXT
배터리 진단

MAYDAY OBI는 ESP32-S3 기반의 마끼다 LXT 배터리 진단 장치입니다. 3.5인치 터치스크린에서 배터리 정보를 확인할 수 있습니다.

컴퓨터와 보드를 연결하면
여기서 바로 설치할 수 있습니다.

웹 설치 준비

MAYDAY OBI · ESP32-S3

설치 가능한 펌웨어를 확인하고 있습니다.

  1. PC의 Chrome 또는 Edge에서 이 페이지를 엽니다.
  2. 데이터 전송이 가능한 USB 케이블로 보드를 연결합니다.
  3. 설치 버튼을 누르고 보드의 USB 포트를 선택합니다.
  4. 설치 완료 안내가 나올 때까지 케이블을 연결해 둡니다.

이 홈페이지에 안내된 3.5인치 보드용입니다. 설치 중에는 마끼다 배터리 연결을 분리해 주세요. 설치 방식과 지우기 선택에 따라 기존 설정이 초기화될 수 있습니다.

USB 포트가 보이지 않거나 연결되지 않나요?

충전 전용 케이블 대신 데이터 케이블을 사용하고, 다른 프로그램의 시리얼 모니터를 닫아 주세요. 그래도 연결되지 않으면 보드의 BOOT 버튼을 누른 상태에서 RESET을 짧게 누른 뒤 BOOT을 놓고 다시 연결해 보세요. 보드에 따라 버튼 이름과 진입 방법이 다를 수 있습니다.

사용 보드와 배선

ESP32-S3 · 3.5인치 터치스크린. 실제 후면 사진과 마끼다 통신 배선 · 리튬이온 전원 배선을 확인하세요.

리튬이온 배터리 연결도

배선도 확대 ↗ 배선도 확대 ↗

배터리 + / −는 P5 전원 단자에 연결합니다. 전압 측정용 두 가닥에는 각각 100kΩ 저항을 넣고, 두 저항이 만나는 지점을 기판에 표시된 IO9에 연결합니다.

보호회로가 있는 1셀(1S) 배터리를 사용하고 P5의 실제 +/− 극성을 확인하세요.

구매 전 보드 규격과 커넥터 구성이 사진과 같은지 확인하세요.
